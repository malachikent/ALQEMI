User Guide
==========

How ALQEMI works, one topic per page. Each page has short examples you can paste
into Python. They are tested, so they show real output.

The mathematics follows Helgaker, Jørgensen and Olsen, *Molecular
Electronic-Structure Theory* (HJO), chapter 1. Equation numbers such as (1.8.14)
refer to that book. ``MATHEMATICAL_CONTRACT.md`` in the repository states every
convention precisely, and ``DESIGN_DECISIONS.md`` records why each choice was made.
