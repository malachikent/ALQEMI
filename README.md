This is a package for Automated Logic for Quantum Expression, Manipulation, and Implementation

ALQEMI derives second-quantized equations (coupled-cluster amplitude equations and
more) with the commutator identities of Helgaker, Jørgensen and Olsen, without Wick's
theorem, and prints them as LaTeX or numpy `einsum` code, in spin-orbital or UHF
spin-integrated form.

**Documentation:** https://alqemi.readthedocs.io/ (getting started, cheatsheet, user
guide, and tutorials from MP2 to UHF-CCSD checked against Psi4 and PySCF).
